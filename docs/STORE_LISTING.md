# ストア掲載情報（ASO）

App Store Connect / Google Play Console にそのまま貼れる形でまとめる。
**文字数は各ストアの上限に収めてある。**貼る前に上限が変わっていないか一応確認すること。

## App Store

### 名前（30文字以内）

```
ラキカラ - パーソナルカラー診断
```

> 22文字。ホーム画面のアイコン下には「ラキカラ」だけが出る。

### サブタイトル（30文字以内）

```
骨格診断×毎日の占いで今日の色
```

> 15文字。名前で拾えない「骨格診断」「占い」をここで拾う。

### プロモーションテキスト（170文字以内・審査なしで差し替え可）

```
毎朝5時に更新。今日のラッキーカラーと、あなたに似合う色を掛け合わせて、コーデ・ネイル・ヘアアクセを提案します。診断は10問ずつ。まずはパーソナルカラーから。
```

### 説明（4000文字以内）

```
「今日、何色を着よう？」に毎日こたえる診断アプリ。

パーソナルカラーと骨格を10問ずつの診断で調べて、毎日変わる占いと掛け合わせます。
自分に似合う色は変わらないけれど、今日のラッキーカラーは毎日変わる。
その2つが重なったところに、今日のあなたに似合うものがあります。

◆ パーソナルカラー診断（10問）
手首の血管の色、日焼けしたときの反応、似合うアクセの金属色。
鏡を見ればその場で答えられる質問だけなので、迷わず進められます。
イエベ春・ブルベ夏・イエベ秋・ブルベ冬の4タイプから判定します。

◆ 骨格診断（10問）
手首の骨の形、鎖骨の見え方、得意なシルエット。
ストレート・ウェーブ・ナチュラルの3タイプから判定します。
「似合うものを見つける」ための診断なので、体型の良し悪しには触れません。

◆ パーソナルカラー × 骨格
2つの結果を掛け合わせて、色と素材とシルエットをまとめて提案します。
12通りそれぞれに違うアドバイスを用意しました。

◆ 今日のおすすめ
星座ごとの今日の運勢と、あなたに似合う色を掛け合わせます。
ラッキーカラーが得意な色なら、その色でコーデ・ネイル・ヘアアクセを。
得意な色でなければ、ネイルや小物で少しだけ取り入れる方法を提案します。

◆ 相性診断
自分の星座と、相手の誕生日から相性がわかります。
恋愛だけでなく、友達や部活の相手としても読める内容にしました。
入れた相手の誕生日は保存も送信もされません。

◆ シェア
診断結果をカードにして保存・共有できます。

--------------------

【安心して使えるように】
・会員登録はいりません
・誕生日や診断結果は、この端末の中だけに保存されます。どこにも送信しません
・広告は非パーソナライズ広告のみ。トラッキング許可の確認は表示しません

【ご利用にあたって】
占いおよび診断の内容は娯楽を目的としたものです。
進路・健康・金銭などの重要な判断には使わないでください。
```

### キーワード（100文字以内・カンマ区切り）

## 年齢レーティング

### App Store（App Store Connect のアンケート）

| 質問 | 回答 |
|---|---|
| 暴力・性的表現・不適切な言葉 | すべて「なし」 |
| ギャンブル | なし |
| **占い・オカルト（Horoscopes / Fortune Telling）** | **あり（頻度: まれ/軽度）** |
| 医療・治療情報 | なし |
| ユーザー生成コンテンツ | なし |
| 制限なしのWebアクセス | なし |
| 年齢制限 | **12+**（占いの項目により 12+ になる想定） |

> **「子供向け」設定はオフのままにする。**キッズカテゴリには登録しない（`docs/SPEC.md` §8）。

### Google Play（コンテンツのレーティング アンケート）

| 質問 | 回答 |
|---|---|
| カテゴリ | ユーティリティ / その他 |
| 暴力・性的表現・不適切な言葉・薬物 | すべて「いいえ」 |
| ギャンブル | いいえ |
| ユーザー間のやり取り | いいえ |
| 位置情報の共有 | いいえ |
| 個人情報の収集 | いいえ |

### Google Play データセーフティ

| 項目 | 回答 |
|---|---|
| データを収集するか | **いいえ** |
| データを共有するか | **いいえ** |
| 広告IDの使用 | 広告SDKが端末識別子を使う可能性があるため、AdMob の申告内容に合わせる |
| データの暗号化 | 該当なし（送信するユーザーデータがない） |
| データ削除のリクエスト | 該当なし（アプリ削除で端末内のデータも消える） |

> 広告SDKの申告は Google の案内に従うこと。非パーソナライズ広告のみでも
> 広告IDに触れる場合があるため、AdMob 側のドキュメントを確認して回答する。

## スクリーンショット

`tool/screenshots/` で生成できる。必要なサイズは:

| ストア | 必要なもの |
|---|---|
| App Store | iPhone 6.9インチ（1290×2796 など）… 最低1枚、推奨3〜5枚 |
| Google Play | 携帯電話用 最低2枚（1080×1920 以上） |

載せる画面の順番（おすすめ）:

1. 診断結果（イエベ春）— 何が得られるかが一目でわかる
2. ホーム — 機能の全体像
3. 今日のおすすめ — 毎日開く理由
4. 診断の質問 — 手軽さ
5. 相性診断 — おまけの楽しさ
